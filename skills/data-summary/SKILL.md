---
name: data-summary
description: 对用户在对话中提供的数值做描述性统计，解释口径、单位和结果的适用范围。
---

当用户提供一组数值并要求统计时：

1. 明确单位、时间范围与缺失值，不自行把缺失值当作零。
2. 使用 calculate_statistics 计算数量、总和、平均值、最小值、最大值；不心算编造工具结果。
3. 用 Markdown 表格展示结果，说明样本是否足以支持用户结论。
4. 未连接任何数据平台时，只处理用户提供的数据，明确无法自动获取数据库内容。
5. 不执行 Python、SQL 或 Shell 脚本，不要求用户提交数据库密码或 API 密钥。
